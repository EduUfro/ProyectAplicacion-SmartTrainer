# ProyectAplicacion-SmartTrainer
SmartTrainer
Smart Trainer es un proyecto de aplicación móvil orientada a personas que desean comenzar a entrenar y llevar un registro de su actividad física de manera sencilla. Su objetivo es reunir en un solo lugar la planificación de entrenamientos, la consulta de ejercicios y el seguimiento del progreso personal, con integración prevista para dispositivos smartwatch.

tegnologias a utilizar dentro del proyecto:
Aplicación móvil	Android (Java)
Base de datos	PostgreSQL
Autenticación	BCrypt 
Integración wearable	Health connect
Frontend móvil	Flutter
Lenguaje del frontend	Dart
Backend	Java + Spring Boot


Funcionalidades previstas
- Registro e inicio de sesión: creación de cuentas y autenticación de usuarios.
- Catálogo de ejercicios: consulta de ejercicios organizados por grupo muscular, con descripción, dificultad y material visual.
- Registro de entrenamientos: seguimiento de los ejercicios realizados y de la actividad registrada.
- Plan semanal: organización y consulta de las sesiones de entrenamiento programadas.
- Historial: acceso a entrenamientos anteriores.
- Seguimiento del progreso: consulta de resúmenes y estadísticas de entrenamiento.
- Músculos trabajados: visualización de grupos musculares ejercitados.
- Videos demostrativos: recursos visuales para apoyar la ejecución de ejercicios.
- Integración con smartwatch: sincronización de datos compatibles de actividad física, según las posibilidades del dispositivo y las API utilizadas.
- Perfil personal: consulta de información del usuario y cierre de sesión.
